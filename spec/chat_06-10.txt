User: React code is unable to show image but shows message Failed to fetch. What is the reason

Assistant:
## Root Cause

The likely cause is **CORS**, not React’s ability to display the image. The app fetches `http://localhost:8080/generate-image` from Vite on port `3000` in `React_Website/src/App.jsx`, which is a cross-origin browser request. The Spring controller returns the image bytes, but there was no CORS configuration; the browser can block the response, causing `fetch` to reject with **“Failed to fetch”** before React receives a blob to display.

## Recommended Fixes

1. Configure Spring to allow requests from `http://localhost:3000` for the image endpoint in `src/main/java/demo/apring/ai/demo/controller/GenAIController.java` or via a shared CORS config.
2. Check the browser console/network panel for a CORS error. If there isn’t one, verify the frontend’s `localhost:8080` URL reaches the backend from the browser’s machine.

User: How to configure Spring for CORS

Assistant:
For this app, the simplest fix is to allow the Vite origin on the image endpoint. Add `@CrossOrigin` to `getImage` in `GenAIController`:

```java
import org.springframework.web.bind.annotation.CrossOrigin;

@CrossOrigin(origins = "http://localhost:3000")
@GetMapping("/generate-image")
public ResponseEntity<byte[]> getImage(
        HttpServletResponse response,
        @RequestParam String prompt) throws IOException {
    // existing implementation
}
```

If the recipe endpoint also needs browser access, put `@CrossOrigin(origins = "http://localhost:3000")` on the controller class instead. Restart Spring after the change.

If Spring Security is configured, also enable CORS in its security configuration; otherwise, security may reject the request before MVC’s CORS settings apply.
